# CRM Mobile (Ionic) — Phase 2

This app will be built in Phase 2 using Ionic + Capacitor.

## Planned Features
- Same domain/application layer as desktop
- Capacitor for native mobile features
- Manual sync with desktop SQLite
- WhatsApp Twilio notifications

## Setup (Phase 2)
```bash
# Will use Ionic CLI to scaffold
ionic start mobile-ionic blank --type=angular --capacitor
```
